Explique com suas palavras qual problema o Factory resolve. O que aconteceria se os ifs que decidem qual objeto criar ficassem espalhados pelo main e por outras partes do programa, e depois surgisse um tipo novo?
A Factory serve para criar um obejto ela centraliza tudo em uma classe só evitando que ao fazermos uma alteração tenhamos que modificar o codigo em varios pontos.
Caso os ifs ficassem espalhados pela main ou restante do codigo ao sofrer uma alteração ou acrescentar outro objeto teriamos um trabalho de prrocurar onde está essas informações e deixa o codigo extenso e desorganizado.

Questão 4. Seu sistema precisa usar uma classe de pagamento de outra empresa, mas ela não implementa a sua interface. Por que não dá para simplesmente escrever implements na classe dela? O que você faz no lugar?
É porque a classe externa não foi criada para implementar a nossa interface e não podemos alterar diretamente o código dela (por exemplo, quando vem de uma biblioteca de terceiros).
Criamos uma classe Adapter que implementa nossa interface e utiliza a classe externa por dentro.
